# 移动端适配 · 验收清单（第一批）

> 适用范围：第一批（竖屏提示 / 字号下限 / 44px 热区 / 触摸行为 / 后台暂停 / 返回键兜底）。
> 目标：PC 端零回归，手机横屏原生可玩，竖屏只做提示。
> 标记：`[自动]` 可一键跑；`[人工]` 需真机肉眼/手感确认。

## 一、一键命令

```bash
# 1) CSS 静态断言（媒体查询分层、字号写法、热区归属）
node js/dev/css-audit.js

# 2) 可暂停定时器单测（Node 虚拟时钟）
node js/dev/timer-test.js

# 3) 出题自检（42 关 × 30 次）
node js/dev/selfcheck.js

# 4) 运行时行为验证（倒计时冻结/恢复、结算定时器暂停、返回键）
node js/dev/capture.js /tmp/pc --verify-behavior 1

# 5) PC 视觉回归：出图 + 与基线逐像素比对（必须 0 差异）
node js/dev/capture.js /tmp/pc
node js/dev/pixel-diff.js js/dev/baseline/pc1920 /tmp/pc

# 6) 手机横屏断言（844×390 / iPhone SE 667×375）
node js/dev/capture.js /tmp/ms --width 844 --height 390 --mobile 1 --assert-mobile 1 --dpr 2
node js/dev/capture.js /tmp/se --width 667 --height 375 --mobile 1 --assert-mobile 1 --dpr 2

# 7) 竖屏提示断言（390×844）
node js/dev/capture.js /tmp/pt --width 390 --height 844 --mobile 1 --assert-mobile 1 --dpr 2
```

`--mobile 1` 用 CDP `Emulation.setTouchEmulationEnabled` 让 `pointer: coarse` 生效，等价于触屏设备。

## 二、PC 回归（必须全绿）

- `[自动]` 1920×1080 六屏（开始/地图/关卡/结算/商店/皮肤）与 `js/dev/baseline/pc1920` **逐像素 0 差异**（tolerance=0）。
- `[自动]` 六屏关键元素计算样式快照与基线一致（见 `pixel-diff` 第二个区块）。
- `[自动]` 页面无 JS 报错。
- 基线不接受的变更：任何在 PC 上生效的字号/尺寸/间距/颜色改动。新增规则必须落在媒体查询内。

### 触控本（any-pointer: coarse + pointer: fine）

没有 Windows 触控本，真机部分**不冒充已验**，按「静态断言 + 代码审查」降级：

- `[自动]` `css-audit` 保证：字号规则只存在于 `(pointer: coarse)` 且写在 `mobile.css`；`touch-action`/`-webkit-touch-callout`/热区伪元素只存在于 `(any-pointer: coarse)`；`:hover` 必须 `(hover: hover) and (pointer: fine)`。
- `[自动]` PC 基线 diff 0（纯鼠标路径）。
- `[人工/待补]` 触控本上 `.pager-arrow` / `.btn-tool` **允许 1~2px 视觉差异**：这两处 `::before`/`::after` 已被玻璃高光占用，且父级 `overflow: hidden` 会裁掉向外扩的伪元素，因此改为元素盒补足 44px（`min-width/min-height`）。`any-pointer: coarse` 命中时盒子变大 1~2px，属预期，不视为回归。
- `[自动]` 该差异不得挤压排版：道具方块两两不相交、箭头不压页点、箭头不压商品卡、货架可视宽度 A/B 一致（去掉 `min-width` 后宽度不变）。

## 三、手机横屏（可玩性）

- `[自动]` 34 项断言：字号下限逐项、`scrollWidth ≤ clientWidth` 逐项（商品名 23、价格 23、品类行 2、清单行 2、清单标题 1，**不抽样**）、热区尺寸/四角在舞台内/命中、挤压断言、竖屏提示不出现。
- `[自动]` 热区四角坐标输出示例（844×390，舞台 `(75,0)–(769,390)`）：
  - `.btn-back-game`：元素 24×24，`::after` 44×44，热区 `(89,14) (133,14) (89,58) (133,58)`，四角均在舞台内，圆角 12px 内缩 5px 后 4 角 + 中心 5/5 命中。
  - `.pager-arrow`：热区 44×44，四角 `(361,331) (405,331) (361,375) (405,375)`，5/5 命中。
  - `.btn-tool`：热区 44×44，四角 `(609,7) (653,7) (609,51) (653,51)`，5/5 命中。
  - 说明：圆角控件的**真角点落在圆角透明区**，不参与命中；命中判定按圆角内缩后的 4 角 + 中心。若某角超出舞台被裁，断言会输出裁剪后的实际有效尺寸。
- `[人工]` **可读性**：667×375 与 844×390 真机上肉眼确认 10px 档（品类说明行、品类限制行、商品名、道具小字、角标）可读。
  - 溢出断言只能证明「没被裁断」，**不等于可读**。
- `[人工]` 商品图放大后手指点选准确率、连点两次取消、翻页箭头点按手感。

## 四、竖屏（只验提示层）

竖屏不提供可玩布局，只展示「把手机横过来玩吧」提示层。

- `[自动]` 提示层 `display: flex`、卡片完整在视口内（390×844 实测 335×251 @ (27,296)）、关闭按钮可见。
- `[人工]` 真机确认提示层文案 18px（标题）/14px（正文）可读，「仍要继续」按钮可点。

## 五、后台与动画（冻结语义，统一口径）

- **关卡倒计时**：切后台冻结（停表），回前台按剩余时长继续，不补偿后台时间。
- **结算 / 存钱罐动画**：切后台暂停、回前台继续（不是「后台跑完」，也不是「不冻结」）。实现上用 `ZQ.timer.*` + `body.is-paused` 暂停 CSS 动画。
- `[自动]` `--verify-behavior` 覆盖：`切后台倒计时冻结`、`is-paused` 生效、`animation-play-state=paused`、`回前台倒计时继续`、`后台期间结算定时器不跑`、`回前台后结算定时器补跑`。

## 六、返回键（Android / 手势返回）

策略：**屏幕级切换才入栈**，弹窗只关弹窗不跳屏。

- `[自动]` 弹窗（结算 / 存钱罐 / 设置 / 聚光提示）不调用 `ZQ.app.go()`，由 DOM 开关控制。
- `[自动]` 地图 → 开始：`go()` 用 `replaceState`，地址栏与画面一致，不形成「返回→再进」循环。
- `[自动]` 开始页首次返回：拦截 + 补一条历史（条目不增不减）+ 弹「再按一次返回键退出游戏」；2.5s 窗口过期后再次按会重新提示。
- `[人工]` 真机确认：
  - 大厅 → 地图 → 返回 → 停在开始页，不是空白页；
  - 地图 → 关卡 → 返回 → 回到地图，不是直接回大厅；
  - 开始页 2.5s 内连按两次 → 按浏览器行为退出（页面内无法断言退出本身，只能真机看）；
  - 地址栏 hash 是否稳定（不被重载刷掉）。
- 已知限制：若用户手动输入 URL 进入，本页就是历史栈第一条，跨文档返回无法被 JS 拦截，不属于本实现缺陷。

## 八、已知限制（非缺陷）

- `file://` 下妈妈立绘环境光（`mask-image`）会报 `CORS policy`，图像主体正常；`http://` 下无此报错。
- 圆角控件的热区真角点不可命中（圆角透明区），命中按内缩判定。
